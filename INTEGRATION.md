# Integration branch of open PRs

> ⚠️ Experimental branch for joint testing, NOT a release.

All open non-draft PRs applied in ascending order, one PR = one squash commit
(`PR #N: <title>`). PRs conflicting with already-applied ones are skipped.
Syntax-checked with `php -l`. Authorship of each commit belongs to the
respective PR author. This branch itself is not an upstream PR.
